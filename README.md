# Blinkit_Analysis

## 📊 Project Overview

This project analyzes Blinkit's sales, customer, product, inventory, delivery, and marketing data using **Power BI**. The objective is to transform multiple raw datasets into an interactive dashboard that provides insights into sales performance, product categories, regional trends, customer feedback, and delivery performance.

The project demonstrates an end-to-end data analysis workflow, including **data consolidation, data cleaning, transformation, data modeling, DAX calculations, KPI creation, and interactive visualization**.

---

## 🎯 Objectives

* Analyze overall sales and order performance.
* Identify trends across products and product categories.
* Compare sales performance across regions.
* Analyze customer ratings and feedback.
* Examine delivery performance.
* Monitor inventory-related information.
* Create interactive KPIs and visualizations for business analysis.

## 🔄 Data Analysis Workflow

### 1. Data Collection

Collected multiple CSV datasets containing sales, customer, product, inventory, delivery, and marketing information.

### 2. Data Cleaning & Transformation

Used **Power Query** to:

* Import multiple CSV files
* Clean and transform raw data
* Handle data types
* Prepare datasets for analysis
* Create a structured data model

### 3. Data Modeling

Created relationships between relevant tables to connect information across:

* Customers
* Orders
* Order Items
* Products
* Inventory
* Delivery
* Marketing
* Customer Feedback

### 4. DAX Analysis

Created DAX measures to calculate important **Key Performance Indicators (KPIs)** and support sales performance analysis.

### 5. Dashboard Development

Designed an interactive Power BI dashboard with drill-down analysis across **3 dimensions**:

* **Product**
* **Region**
* **Time**
